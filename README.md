# OtherSMTP4Gmail

Gmailの作成画面から、別途用意したSMTPサーバーを使ってテキストメールを送信する、Windows向けChrome拡張機能です。Chromeウェブストアを介さず、パッケージ化されていない拡張機能として読み込みます。Gmailの画面連携について、MailBridgeの動作とコードの調査を参考にしています。

## 必要なもの

- Windows 10 / 11、Google Chrome
- SMTPサーバーの接続情報と、送信元アドレス
- [mailsend-go のWindows版](https://github.com/muquit/mailsend-go/releases)（別途ダウンロード）

本ツールにはmailsend-goを同梱していません。ダウンロードしたZIPを展開し、`mailsend-go-v1.0.14-windows-amd64.exe` のようなexeの場所を確認してください。バージョンによってファイル名は変わります。

## インストール

1. Releasesから `OtherSMTP4Gmail.zip` をダウンロードし、使用し続けるフォルダーに展開します。
2. 展開先をエクスプローラーで開き、アドレス欄に `powershell` と入力してPowerShellを開きます。
3. `powershell -ExecutionPolicy Bypass -File .\install.ps1` を実行します。現在のWindowsユーザーに連携プログラムを登録します。管理者権限は不要です。
4. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にします。
5. 「パッケージ化されていない拡張機能を読み込む」で、展開先の `extension` フォルダーを選びます。
6. 拡張機能のアイコンから設定を開き、mailsend-goのexeファイル名まで含むフルパスを入力して保存します。
7. 「送信元を追加」からSMTP設定を登録し、Gmailを再読み込みします。アドレスは `Sample@Sample.com` のような形式です。サーバー名、ユーザー名、ポートは利用中のメール事業者の指定に従ってください。

フォルダーを移動した場合は移動先で `install.ps1` を再実行し、mailsend-goの場所も必要に応じて設定し直してください。同じ連携プログラム名を別のフォルダーから登録済みの場合は衝突を防ぐため停止します。既存の登録を確認してから切り替えてください。

## 使い方

設定画面で最大10件のSMTPアカウントを登録し、上下ボタンでGmail通常送信を含む選択肢の順序を変更できます。一覧の先頭が新規メールや返信の初期値になります。作成画面で送信元、宛先、件名、本文、添付を確認してから送信してください。返信時は元メールの識別子を取得し、返信ヘッダーを付けます。

送信履歴が必要な場合は、SMTP設定の「送信履歴 Bcc」に受信用アドレスを指定します。Gmailのフィルタとラベルを設定すると履歴をまとめられます。これは受信したコピーであり、Gmail標準の「送信済み」には入りません。Bccを空欄にするとコピーは送信されません。

## 設定と資格情報

SMTPサーバーの設定は `smtp.ini` に保存します。パスワードはWindowsの資格情報マネージャーに保存され、INIには保存されません。設定編集時にパスワードを空欄にすると、保存済みの値を維持します。認証不要のサーバーではユーザー名とパスワードを両方空欄にします。

資格情報は現在のWindowsユーザーとPCに紐付くため、別の環境にINIだけをコピーした場合はパスワードを再入力してください。以前のINIにパスワードがある場合、初回読み込み時に資格情報へ移してINIから該当項目を削除します。移行前のバックアップには平文パスワードが残る場合があります。

暗号化方式の初期ポートはSTARTTLSが587、SSL/TLSが465、暗号化なしが25です。事業者の指定に合わせて変更できます。暗号化なしではパスワードやメール内容が通信経路上で見える可能性があります。通常は暗号化と証明書の検証を有効にしてください。

## 制限と注意

- 日本語を含むプレーンテキストメールに対応します。本文内画像、HTML書式、Googleドライブのファイルチップは送信しません。
- 添付ファイルは最大10個、合計10 MiBまでです。アップロードが完了してから送信してください。
- 空の本文と、本文中の文字列 `\n` には対応していません。
- Gmail画面の仕様に依存するため、Google側の変更によって動作しなくなる場合があります。返信元や添付が正しく取得できない場合は送信を中止します。
- 送信後にGmailの下書きを破棄します。送信中に内容が変わった場合や破棄できなかった場合は下書きが残ります。
- 通信エラーやタイムアウト時は送信済みの場合があります。再送前に履歴や相手への到達状況を確認してください。
- 送信処理中、本文と添付をWindowsの一時フォルダーに置き、終了時に削除を試みます。異常終了時には残る場合があります。

## 構成

`extension` はChrome拡張機能、`LocalSmtpHost.exe` は拡張機能とWindowsを接続するプログラムです。`native` のC#ソースから `build.ps1` で再ビルドできます。mailsend-goは独立した外部プログラムです。
